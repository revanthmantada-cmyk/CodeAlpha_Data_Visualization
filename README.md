# CodeAlpha Task 2 – Data Visualization

## Project Title
Student Performance Data Visualization Dashboard

## Internship
CodeAlpha – Data Analytics Internship

## Project Overview
This project focuses on visualizing student academic performance using Python. The Student Performance Dataset was used to create charts and graphs to identify patterns and trends.

## Dataset Details
- Total records: 395 students
- Total columns: 33
- Dataset: student_data.csv

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Visualizations Created
1. Final Grade Distribution – Histogram
2. Study Time vs Average Grade – Bar Chart
3. Correlation Heatmap
4. Student Absences – Box Plot
5. Gender Distribution – Pie Chart
6. Study Time vs Final Grade – Strip Plot
7. Combined Student Performance Dashboard

## Project Objectives
- Convert raw data into meaningful visualizations.
- Understand student academic performance.
- Identify patterns in grades and study-time categories.
- Explore relationships between numerical variables.
- Present insights using a dashboard.

## Conclusion
This project demonstrates how Python visualization libraries can help transform student data into meaningful graphical insights and make information easier to understand.
